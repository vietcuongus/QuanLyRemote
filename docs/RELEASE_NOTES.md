QuanLyRemote v1.0.3 — kéo thả tab và Ctrl + C thông minh.

- Kéo phần tên tab sang trái/phải để đổi thứ tự, có vạch đánh dấu vị trí thả.
- Giữ nguyên tab đang chọn và các kết nối đang chạy; thứ tự mới được lưu để mở lại.
- Focus tên tab rồi dùng Alt + Shift + ←/→ để sắp xếp bằng bàn phím.
- Ctrl + C sao chép phần đang bôi đen trong terminal, không hủy lệnh đang chờ.
- Khi không bôi đen, Ctrl + C vẫn ngắt lệnh. Ctrl + Shift + C và nút Sao chép vẫn hoạt động.
- Giữ tự khôi phục phiên của 1.0.2 và sửa Ctrl + V của 1.0.1.

Đóng tool cũ rồi chạy setup để cài đè trên cùng tài khoản Windows; các kết nối và mật khẩu đã lưu được giữ nguyên.
Đã kiểm thử kéo thả chuột, thứ tự tab sau khởi động lại, clipboard Windows và byte nhận qua SSH trên desktop và bản đóng gói.
Windows 10/11 x64. Bản chưa ký số; SHA256SUMS.txt đi kèm release.
